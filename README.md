<h1>Hello World – Lernia</h1>

<p>
  I created this simple web application for my web development course at Lernia.
  It uses HTML, CSS and JavaScript.
</p>

<p>
  The page shows <strong>Hello World</strong> in blue, with a
  <strong>Change text</strong> button below it. Clicking the button changes
  the heading to <strong>Goodbye World</strong>.
</p>

<h2>Project files</h2>

<ul>
  <li><code>index.html</code> – The page structure, heading and button.</li>
  <li><code>style.css</code> – The colours and styling.</li>
  <li><code>script.js</code> – The code that changes the heading when the button is clicked.</li>
</ul>

<h2>How to run</h2>

<p>
  Open <code>index.html</code> in a browser or use
  <strong>Live Server</strong> in VS Code.
</p>
