Hello World – Lernia

I created this simple web application for my web development course at Lernia. It uses HTML, CSS and JavaScript.

The page shows Hello World in blue, with a Change text button below it. Clicking the button changes the heading to Goodbye World.

The project has three files:

index.html – The page structure, heading and button.
style.css – The colours and styling.
script.js – The code that changes the heading when the button is clicked.

To run the application, open index.html in a browser or use Live Server in VS Code.
